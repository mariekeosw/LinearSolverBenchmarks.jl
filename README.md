# LinearSolverBenchmarks.jl -- Benchmarking linear solvers for elliptic PDEs and drift-diffusion systems

`LinearSolverBenchmarks.jl` is a Julia framework for comparing direct and iterative solvers for sparse linear systems arising from elliptic partial differential equations and semiconductor device simulations.

The code was developed as part of the master's thesis *Iterative Solvers and Preconditioners for Drift-Diffusion Systems*. It contains the benchmark setups, solver configurations, runtime measurements, and post-processing routines used in the numerical studies.

## Overview

The repository contains two benchmark applications:

- an elliptic model problem in one, two, and three spatial dimensions, and
- stationary two- and three-dimensional MOSFET simulations based on the van Roosbroeck drift-diffusion system.

The MOSFET simulations rely on [`ChargeTransport.jl`](https://github.com/WIAS-PDELib/ChargeTransport.jl), which discretizes the drift-diffusion equations using the Voronoi finite-volume method implemented in [`VoronoiFVM.jl`](https://github.com/WIAS-PDELib/VoronoiFVM.jl). Benchmark results are stored in JLD2 files and can be processed using the plotting and table-generation scripts included in this repository.

The benchmark framework uses the common solver interface provided by [`LinearSolve.jl`](https://github.com/SciML/LinearSolve.jl) and combines it with the following direct solvers, Krylov methods, and preconditioners:

| Category | Methods, variants, and implementations |
| --- | --- |
| Direct solvers | UMFPACK and KLU from [SuiteSparse](https://github.com/DrTimothyAldenDavis/SuiteSparse), MKLPardiso through [`Pardiso.jl`](https://github.com/JuliaSparse/Pardiso.jl), and Sparspak through [`Sparspak.jl`](https://github.com/PetrKryslUCSD/Sparspak.jl) |
| Krylov methods | CG for symmetric systems and CGS, BiCGSTAB and GMRES for nonsymmetric systems, implemented by [`Krylov.jl`](https://github.com/JuliaSmoothOptimizers/Krylov.jl) and accessed through `LinearSolve.jl` |
| Incomplete factorizations | ILU with drop tolerances `0.01` and `0.1` from [`IncompleteLU.jl`](https://github.com/haampie/IncompleteLU.jl), and ILU(0) from [`ILUZero.jl`](https://github.com/mcovalt/ILUZero.jl) |
| Algebraic multigrid | Ruge–Stüben and smoothed-aggregation AMG provided by [`AMGCLWrap.jl`](https://github.com/j-fu/AMGCLWrap.jl) (Wrapper around a subset of [AMGCL](https://github.com/ddemidov/amgcl)), [`AlgebraicMultigrid.jl`](https://github.com/JuliaLinearAlgebra/AlgebraicMultigrid.jl), and [`LinearSolvePyAMG.jl`](https://github.com/SciML/LinearSolve.jl/tree/main/lib/LinearSolvePyAMG); SPAI(0) and ILU(0) are considered as relaxation methods in AMGCL |
| Block preconditioners | Equation-based and node-based block-Jacobi preconditioners implemented using the preconditioner interface provided by [`ExtendableSparse.jl`](https://github.com/WIAS-PDELib/ExtendableSparse.jl) |

**Note on benchmarking:** Runtime measurements are performed using Julia's built-in `@elapsed` macro and the `@belapsed` macro provided by [`BenchmarkTools.jl`](https://github.com/JuliaCI/BenchmarkTools.jl). The `@elapsed` strategy performs a single timed run and records setup and solve times separately, whereas `@belapsed` performs repeated measurements to obtain a more robust runtime estimate.


## Directory structure

The repository is organised into the following main folders:

- **`jld2_files_server/`**
  Contains the JLD2 result files generated by the benchmark runs on the server, including problem sizes, runtimes, residuals, and iteration counts where applicable.

- **`src/`**
  Contains the reusable package code. The `model_problem/` subfolder defines the solver configurations for the elliptic benchmark. The `mosfet/` subfolder contains the MOSFET solver configurations, grids, parameter sets, simulation routines, and export utilities.

- **`scripts/`**
  Contains the main entry points for running the model-problem and MOSFET benchmarks. It also includes additional scripts for analysing the MOSFET doping profile and gate properties.

- **`post_process/`**
  Contains scripts for generating the figures and LaTeX tables used in the numerical studies. The scripts are grouped by benchmark problem and, for the MOSFET, by spatial dimension and comparison setup.

Benchmark and simulation results are written to JLD2 files in the directory from which the corresponding script is executed.

## Usage

To run the examples, you need a Julia installation with version 1.10 or later.

### 1. Clone the repository

```bash
git clone https://github.com/mariekeosw/LinearSolverBenchmarks.jl
cd LinearSolverBenchmarks.jl
```

### 2. Instantiate and activate the project dependencies

Start Julia with the repository environment and install all required dependencies:

```bash
julia --project
julia> using Pkg; Pkg.instantiate()
julia> using Pkg; Pkg.activate("./")
```

This step is required only once for a given Julia environment and may take several minutes.

### 3. Run the elliptic model problem

The following example performs one solve of the symmetric two-dimensional model problem using the default direct solver:

```julia
include("scripts/run_model_problem_benchmark.jl")

ModelProblemBenchmarkRun.main(
    symmetric = true,
    dimension = 2,
    refinement = 5,
    benchmark_strategy = :elapsed,
)
```

To compare all direct solvers for several refinements and store the results in `model_problem_example.jld2`:

```julia
ModelProblemBenchmarkRun.benchmark(
    "model_problem_example.jld2";
    dimensions = [1, 2, 3],
    refinement_max = 5,
    symmetric = true,
    solver_config = :direct,
    benchmark_strategy = :elapsed,
)
```

The option `benchmark_strategy = :elapsed` performs a single timed run and additionally records the setup time, solve time, and residual. For repeated runtime measurements with `BenchmarkTools.jl`, use `benchmark_strategy = :belapsed`.

The available solver groups are defined in `src/model_problem/benchmark.jl` and are selected through the `solver_config` keyword.

### 4. Run the MOSFET simulation

The following example runs the two-dimensional MOSFET simulation on the coarsest grid using the default direct solver:

```julia
include("scripts/run_mosfet_benchmark.jl")

MosfetBenchmarkRun.main(
    grid_dimension = 2,
    grid_refinement = 0,
    initial_value = :charge_neutrality,
)
```

The simulation writes the equilibrium and biased solutions to `data_mosfet_2d_ref0.jld2`. These solution data include the electrostatic potential, the electron and hole quasi-Fermi potentials, the applied drain-bias values, and the corresponding current-voltage data.

To compare a predefined group of linear solver configurations:

```julia
MosfetBenchmarkRun.benchmark(
    "mosfet_2d_example.jld2";
    grid_dimension = 2,
    grid_refinement_max = 0,
    initial_value = :charge_neutrality,
    solver_config = :direct_all,
)
```
The resulting file `mosfet_2d_example.jld2` contains the benchmark data for the selected solver configurations and grid refinements, including problem sizes, total wall-clock times, linear-solver setup and solve times, Newton iteration counts, and test values.

The available solver groups are defined in `src/mosfet/benchmark.jl` and are selected through the `solver_config` keyword.

### 5. Generate figures and tables

Usage instructions, required input files, plotting backends, and example function calls are documented in comments at the beginning of each script in `post_process/`. Because the required arguments differ between figures and tables, follow the instructions provided in the corresponding script.
